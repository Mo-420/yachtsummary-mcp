# YachtSummary Broker Copilot

This Codex plugin connects to the hosted YachtSummary MCP service.

## Setup

1. Open the public YachtSummary MCP repository in Codex.
2. Approve or enable the plugin if prompted.
3. Sign into YachtSummary through OAuth.
4. Ask:

~~~text
Use YachtSummary and show me my available workflows.
~~~

The plugin is read- and draft-friendly by default. Sending messages or changing YachtSummary records remains controlled by YachtSummary permissions and explicit confirmation.
