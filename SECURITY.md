# Security

Please do not open a public issue containing broker tokens, API keys, customer data, lead exports, private conversations, or live MCP response dumps.

For account or product support, use [YachtSummary support](https://mcp.yachtsummary.com/support).

If you believe you found a security vulnerability, contact YachtSummary privately through its official support channel and include only the minimum information needed to reproduce the issue.
